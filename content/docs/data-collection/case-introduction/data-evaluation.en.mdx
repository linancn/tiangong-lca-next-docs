## Data Availability Assessment

Before modeling, assess the selected data's availability, focusing on input-output material balance. If imbalances exist, analyze reasons based on literature descriptions or process knowledge, and determine if reasonable adjustments (completion, normalization, estimation) can be made to meet modeling requirements. If not, discard the data.

- **Methanol Production Pathway Data Availability Assessment**

**Combining the flow diagram and data content, this case modelling includes two levels: [Unit Process Construction](/en/docs/data-collection/case-introduction/unit-process-construction/) (three single processes) and [Model Building](/en/docs/data-collection/case-introduction/model-building/)**

Each sub-process requires specifying:

- **Reference flow**:
  - Biomass processing: 1kg treated biomass
  - Biomass gasification: 1kg CO  
  - Methanol synthesis: 1kg methanol
- Ensure consistent reference quantities across all processes for correct system calculations

The overall model is a partially terminated system with the third unit process, Methanol Production,
as the baseline. For this case, define the function as providing methanol under stated quality,
boundary, and time conditions, then quantify it with a functional unit such as 1 kg of methanol.
One tonne is only a scale conversion of the same functional basis, not an arbitrary modeller choice.
Each unit process keeps its own reference flow and quantity; exchanges scale them to the shared
functional unit, so their reference quantities do not all need to be identical.

**Processing Notes:**

- **Missing data**: Wastewater amount not provided—estimated based on material balance (details in [Unit Process Construction](/en/docs/data-collection/case-introduction/unit-process-construction/)).

> Important Note:
When required units differ from flow units, perform **unit conversion** rather than creating new Flow items.
