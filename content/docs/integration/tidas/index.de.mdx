`tidas` ist ein eigenständiges Werkzeug für lokale Lebenszyklus-Datenpakete. Es prüft TIDAS JSON, konvertiert eILCD XML, importiert externe Formate und kann mit passender Konfiguration Daten exportieren oder Pakete erstellen.

Es ist kein Alias für `tiangong-lca` und verwendet dessen Anmeldung nicht. Vorgefertigte Programme benötigen weder Node.js noch Python, Java oder eine Rust-Laufzeit. Der Bau aus Quellcode ist eine Entwickleroption.

Zum Einstieg: [tidas installieren](/de/docs/integration/tidas/installation/), danach [das erste Paket prüfen und konvertieren](/de/docs/integration/tidas/first-package/). Das Tutorial verarbeitet nur Übungsdateien auf Ihrem Computer und schreibt nichts auf die Plattform.

Dieses Handbuch verwendet die offizielle Version `tidas 0.2.1`. Für Plattformabfragen nutzen Sie das [CLI-Benutzerhandbuch](/de/docs/integration/cli/), für KI-geführte Aufgaben das [Agent-Skills-Handbuch](/de/docs/integration/skills/).
