---
title: "Local tidas tools"
description: "Install tidas, validate a package, and convert between TIDAS JSON and eILCD XML without platform sign-in."
---

`tidas` is a separate tool for local life-cycle data packages. It validates TIDAS JSON, converts eILCD XML, imports external formats, and—with the appropriate configuration—exports or builds packages.

It is not an alias for `tiangong-lca` and does not use its login. Prebuilt executables require no Node.js, Python, Java, or Rust runtime. Building from source is a developer option.

First time? [Install tidas](/en/docs/integration/tidas/installation/), then [validate and convert your first package](/en/docs/integration/tidas/first-package/). The tutorial only processes teaching files on your computer and writes nothing to the platform.

This guide uses the official `tidas 0.2.1` release. For platform queries, use the [CLI user guide](/en/docs/integration/cli/). For AI-led tasks, see the [Agent Skills guide](/en/docs/integration/skills/).
