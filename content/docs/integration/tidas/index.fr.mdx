title: "Outils tidas locaux"
description: "Installer tidas, valider un paquet et convertir TIDAS JSON en eILCD XML sans connexion à la plateforme."
---

`tidas` est un outil indépendant pour les paquets de données de cycle de vie locaux. Il valide TIDAS JSON, convertit eILCD XML, importe des formats externes et, avec la configuration appropriée, exporte ou construit des paquets.

Ce n’est pas un alias de `tiangong-lca` et il n’utilise pas sa connexion. Les exécutables précompilés ne nécessitent ni Node.js, ni Python, Java ou runtime Rust. La compilation des sources est une option pour développeurs.

Pour débuter, [installez tidas](/fr/docs/integration/tidas/installation/), puis [validez et convertissez votre premier paquet](/fr/docs/integration/tidas/first-package/). Le tutoriel traite uniquement des fichiers pédagogiques sur votre ordinateur, sans écrire sur la plateforme.

Ce guide utilise la version officielle `tidas 0.2.1`. Pour interroger la plateforme, consultez le [Guide utilisateur CLI](/fr/docs/integration/cli/) ; pour des tâches guidées par l’IA, le [Guide Agent Skills](/fr/docs/integration/skills/).
