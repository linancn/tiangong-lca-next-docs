title: "本地 tidas 工具"
description: "不登录平台，在本地安装 tidas、校验数据包，并完成 TIDAS JSON 与 eILCD XML 转换。"
---

`tidas` 是处理本地生命周期数据包的独立工具。你可以验证 TIDAS JSON、转换为 eILCD XML、导入外部格式，也可以在具备相应配置时执行导出或打包。

它不是 `tiangong-lca` 的别名，不依赖 CLI 登录，也不需要 Node.js、Python、Java 或 Rust 运行时。下载预编译程序即可运行；从源码编译是开发者选项。

第一次使用：先[安装 tidas](/zh/docs/integration/tidas/installation/)，再完成[验证并转换第一个数据包](/zh/docs/integration/tidas/first-package/)。教程仅处理你电脑上的教学文件，不写入平台。

本指南使用官方发布的 `tidas 0.2.1`。要查询平台数据，请改用 [CLI 用户指南](/zh/docs/integration/cli/)；让 AI 组织任务时，阅读 [Agent Skills 指南](/zh/docs/integration/skills/)。
