This page supports [Quick Start](/en/docs/quick-start/) by explaining how a literature source,
process data in the platform, a product system, and life cycle impact assessment (LCIA) results
relate. **The paper only supplies background for the example. The platform has not automatically
imported or reproduced its model or conclusions, and this page is not an import-ready package.**

## Sample source

[Comparative environmental assessment of methanol production technologies: A cradle-to-gate life cycle analysis](https://doi.org/10.1016/j.enconman.2024.118128)

## Follow the steps

1. Note the paper title and DOI so you know where the example comes from. Its contents do not
   automatically become platform data.
2. Search Open Data for `methanol`; if there is no exact match, choose any visible process.
3. In process detail, find the reference flow, reference quantity, inputs, and outputs. The reference
   flow says what the process mainly provides and in what quantity; it is not automatically the
   functional unit used to compare a complete study.
4. Open an available LCIA result, note the method, and check how many inputs and emissions have a
   matching calculation factor. A missing factor means incomplete coverage, not zero impact.
5. Use Process Analysis to see which activities contribute most. The practitioner still interprets
   the results against the goal, system boundary, and data limitations and remains responsible for
   the final report.

You can complete these steps without playing the video.
