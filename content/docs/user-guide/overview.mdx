本章节只解释平台界面与操作，不另行规定 LCA 方法。请先回到[文档任务页](/zh/docs/)，选择“分析一个
产品的环境影响”或“整理并发布一份 LCA 数据”；进入本章节后，再按「开始使用、数据与建模、分析
与评审、协作与管理」四组按需查阅。

## 谁适合阅读

- **数据编写者**：需要新建或维护模型、过程与流，关心字段规范与版本管理。
- **审核与质量负责人**：负责把控数据质量、制定审核标准或追踪审核进度。
- **团队协作成员**：在项目中共享数据、协调权限或管理团队资源。
- **分析与应用用户**：需要检索、引用或分析已有数据集。

## 推荐阅读顺序

1. **熟悉界面**
   先阅读[按键功能介绍](/zh/docs/user-guide/key-functions-introduction/)，了解顶部导航、头像菜单、列表操作及常用快捷按钮。

2. **掌握全局导入导出**
   阅读 [TIDAS ZIP 导入、导出与任务中心](/zh/docs/user-guide/tidas-zip-workflows/)，先弄清顶部 ZIP 工作流和后台任务机制。

3. **理解数据模块**
   通过[数据平台介绍](/zh/docs/user-guide/data/)掌握开放数据、我的数据、团队数据之间的权限边界。

4. **构建与维护数据**
   依次阅读[数据新建](/zh/docs/user-guide/create-my-data/)、[数据使用](/zh/docs/user-guide/data-use/)和[数据搜索](/zh/docs/user-guide/search/)，学习从准备素材、建模到引用的全流程。

5. **验证与审核**
   在提交前参考[数据审核](/zh/docs/user-guide/data-review/)的角色分工、审核工作区和检查清单，减少返工。

6. **协作与权限**
   查看[团队功能介绍](/zh/docs/user-guide/team-function/)、[权限与数据空间矩阵](/zh/docs/user-guide/permissions-and-data-scopes/)和[系统管理工作区](/zh/docs/user-guide/system-management/)，明确团队角色、审核角色和系统角色的边界。

7. **深入分析**
   根据需要延伸至[过程分析工作区](/zh/docs/user-guide/process-analysis/)与[LCIA 计算与结果查看](/zh/docs/user-guide/lcia/)。

## 常用入口速查

- 想知道顶部哪个入口负责导入、导出和任务进度？转到[按键功能介绍](/zh/docs/user-guide/key-functions-introduction/)或[TIDAS ZIP 导入、导出与任务中心](/zh/docs/user-guide/tidas-zip-workflows/)。
- 要创建新的流程或模型？按照[数据新建](/zh/docs/user-guide/create-my-data/)的“准备工作→构建数据→校验发布”三个阶段完成。
- 提交审核遇到拦截？在[数据审核](/zh/docs/user-guide/data-review/)查看提交前准备、审核角色与常见问题。
- 需要区分谁能看、谁能改、谁能审核、谁能做系统维护？直接看[权限与数据空间矩阵](/zh/docs/user-guide/permissions-and-data-scopes/)。

## 术语与帮助

LCA、功能单位、系统边界、LCI、LCIA 等专业词见[术语与缩写](/zh/docs/overview/glossary/)；平台中的模型、
过程、流等界面对象见[数据平台介绍](/zh/docs/user-guide/data/)的“核心概念词汇”。若您正在维护文档站本身，
请改看 [Docs / Product 同步指南](/zh/docs/deploy-and-dev/docs-product-sync/)。
