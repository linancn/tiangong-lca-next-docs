---
title: "数据搜索"
---

天工 LCA 平台提供跨字段全文搜索，可在多个数据模块中按名称、分类、流属性和输入输出等字段检索。以下说明当前可验证的搜索范围与行为；实际召回仍受数据范围、索引状态和用户权限影响。

## 搜索功能特点

- **全文搜索**：支持在名称、分类、流属性、输入输出流名称以及系统提取的文本字段中检索
- **智能匹配**：支持模糊搜索、精确匹配和 AI 智能推荐；混合搜索会保留中英文关键词、CAS 号和别名召回，在语义匹配不足时继续使用文本召回；输入包含 `OR` 的组合词时，系统会拆分顶层组合词并保留原始检索词
- **范围与筛选**：搜索会按照当前数据来源范围（天工公开数据、商业数据、我的数据或团队数据）和筛选条件返回结果
- **ID 与引用查找**：输入完整数据集 ID/UUID 时，系统会优先进行精确匹配；在联系人、流、流属性、单位组、来源、过程、模型等列表中，还可以勾选 **引用查找**，用完整数据集 UUID 查看哪些记录引用了这个 ID
- **实时结果**：搜索结果即时呈现，支持多维度筛选和灵活排序

## 搜索示例

### 场景一：过程数据搜索

1. 进入"开放数据"模块
2. 选择"过程"分类
3. 在搜索框中输入"煤炭"
4. 系统将返回所有字段中包含"煤炭"相关内容的匹配结果，包括但不限于名称、分类、输入输出所选择的流的名称等字段

## 注意事项

- 搜索结果受用户权限限制；“我的数据”和“团队数据”搜索只返回当前登录用户有权访问的数据
- 商业数据模块仅显示元数据搜索结果
- 输入中文、英文、常见缩写或 CAS 号时，系统会尽量使用标准别名提升召回稳定性；带括号、引号、反斜杠等特殊字符的原始检索词会先规范化并安全转义后再用于文本召回
- 排查某个 ID 被哪些数据引用时，请复制完整 UUID，在相关数据列表中勾选 **引用查找** 后搜索；如果输入不是完整 UUID，系统会提示补全。引用查找最多展示前 50 条结果；如果结果为空，表示当前数据范围和权限下没有找到引用该 ID 的记录
- 建议使用标准分类体系以提高搜索效率
